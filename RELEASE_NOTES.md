# Pocket Editor — 2026.11.18

Created by **Somi Douth** · somidouth@gmail.com

- Read-only About information with the published author and contact details.
- Project Explorer with Open, Save, and Load project controls.
- Independent Git Project plugin with automatic repository initialization, shared repository services, and repository-local configuration.
- Hosted Team Project with individual client invitations, local project copies, conflict protection, group chat, and file/audio/video attachment exchange.
- OS-detected relay setup, main-window Install Relay / Start Internet Sharing / Stop Sharing controls, and generated shell/PowerShell scripts.
- Public IPv4 lookup with HTTPS fallback services, visible retry errors, and Host/Client connection details.
- One-PC continuous Host/Client test runner using isolated demo files.
- Packaged AI backend source, offline HTML Help, PHP examples and optional dependency manifests.

The source release excludes private settings, recovery sessions, invitation keys, caches, local demo projects, node_modules, audit history, and downloaded executables. The GUI and live relay/file-transfer path have been tested on Debian Linux. Windows/macOS execution remains unverified; OS command/asset selection has automated coverage.
