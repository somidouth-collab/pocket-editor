Pocket Editor documentation

A complete local guide to the editor, its bundled plugins, and building your own tools. Created by Somi Douth · somidouth@gmail.com.

Start in three steps

  1. Launch python3 -B pocket_editor.py from the project directory.
  2. Open files or a project, then use Ctrl+P for file search and Ctrl+Shift+P for commands.
  3. Explore Extensions for plugins, and Help for read-only author and contact information.

Offline by design

Open this HTML file in a browser. No server, account, CDN, JavaScript framework, analytics, or network request is needed to read the documentation. Search works locally when JavaScript is enabled. External reference links require internet access.

Verification scope

The editor and GUI tests were exercised on Linux. Windows/macOS runtime behavior remains unverified. AI integration tests use offline transports; they do not prove provider availability, account access, pricing, or live response quality.
