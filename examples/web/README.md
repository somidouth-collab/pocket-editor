# Web Tools demo

Open this folder in Project Explorer, then open `index.html`, `styles.css` and `app.js`.

- Ctrl+Shift+F formats a web document; Ctrl+Z undoes it.
- Try typing `<di` in HTML, `dis` inside a CSS rule, or `document.que` in JavaScript, then press Ctrl+Space.
- Open Web Tools for installation, syntax checks and saved settings.
- Open `index.html` in a browser to run the demo; it has no build step or external requests.

See [Web Tools Help](../../docs/WEB_TOOLS.md) for setup and supported features.
